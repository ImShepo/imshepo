## Featured Project

### Enterprise E-Billing Platform Migration
*Alteza Enterprise · Backend Tech Lead*

Leading the backend team through a microservices redesign of a mission-critical billing system.

| Problem | Solution | Result |
|---------|----------|--------|
| A high-demand enterprise billing platform was struggling with a monolithic architecture that made scaling, maintenance, and new feature delivery slow and risky. | I led the backend team and designed a microservices architecture with **RabbitMQ** for async event processing, applying SOLID principles and event-driven patterns to decouple the core billing modules. | The platform gained improved modularity, better fault isolation, faster deployment cycles for billing rules, and secure payment gateway integrations with risk analysis. |

`Java` `Spring Boot` `RabbitMQ` `Microservices` `AWS` `Next.js` `React`
